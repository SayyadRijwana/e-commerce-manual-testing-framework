# E-Commerce Platform End-to-End Manual Testing Framework

This repository contains comprehensive manual testing artifacts, quality assurance documentation, and defect tracking logs for an enterprise-level E-Commerce application. The project follows the complete Software Testing Life Cycle (STLC) to ensure functional reliability, security, and exceptional user experience.

## 📌 Project Overview
The target application is a feature-rich E-Commerce platform incorporating critical user workflows such as User Authentication, Product Catalog Search, Shopping Cart Management, and Secure Checkout/Payment Gateways. Testing was executed using black-box testing methodologies to validate business requirements.

### 🌟 Key Testing Types Performed
- *Smoke Testing:* Validating critical build stability before deep testing.
- *Functional Testing:* Verifying component-level business logic specifications.
- *Boundary Value Analysis (BVA) & Equivalence Partitioning (EP):* Validating input field limits.
- *Regression Testing:* Ensuring code updates do not impact existing features.
- *Usability & UI Testing:* Evaluating cross-browser responsiveness and accessibility features.
